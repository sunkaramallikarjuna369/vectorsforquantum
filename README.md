# Vectors in Quantum Computing

Interactive 3D visualizations and comprehensive guide to understanding vectors in quantum computing.

## Overview

This repository provides comprehensive interactive 3D visualizations for all fundamental concepts of vectors in quantum computing. Each concept includes:

- **Interactive HTML pages** with Three.js 3D visualizations
- **Python demonstrations** with NumPy and Matplotlib
- **Mathematical foundations** with formulas and explanations
- **Quantum computing applications** and examples

## Concepts Covered

1. **Introduction** - Vectors as the backbone of quantum mechanics
2. **Mathematical Definition** - Formal definition of vectors, dimensions, components
3. **Addition & Subtraction** - Vector addition represents superposition
4. **Scalar Multiplication** - Complex phase multiplication
5. **Inner Product** - Dot product measures overlap between vectors
6. **Norm (Magnitude)** - Vector length and normalization
7. **Basis Vectors** - Computational basis |0⟩ and |1⟩
8. **Orthogonality** - Orthogonal vectors represent mutually exclusive states
9. **Linear Independence** - Independent basis vectors span Hilbert space
10. **Multi-Qubit Systems** - Tensor products create multi-qubit spaces
11. **Vector Transformations** - Quantum gates as unitary transformations
12. **Outer Product** - Outer products form matrices and density matrices
13. **Bloch Sphere** - 3D geometric representation of qubit states
14. **Exercises** - Practice problems with step-by-step solutions
15. **Summary** - Complete overview with interactive table

## Getting Started

### Viewing the Visualizations

1. Clone this repository:
```bash
git clone https://github.com/sunkaramallikarjuna369/vectorsforquantum.git
cd vectorsforquantum
```

2. Open `index.html` in your web browser to access the main navigation page

3. Click on any concept to explore its interactive 3D visualization

### Running Python Demonstrations

1. Install required dependencies:
```bash
pip install numpy matplotlib
```

2. Run any concept's Python script:
```bash
python 01-introduction/vectors_intro.py
python 02-definition/vector_definition.py
# ... and so on
```
