📐 Mathematical Definition of Vectors

Formal Structure and Notation

Formal Definition

A vector is an ordered collection of real or complex numbers:

v = [v₁, v₂, ..., vₙ]ᵀ

Where:

  • v ∈ ℝⁿ for real vectors
  • v ∈ ℂⁿ for complex vectors (quantum)
  • n is the dimension (number of components)
  • v₁, v₂, ..., vₙ are the components

Classical Example (Real Vector)

v = [3, 4]ᵀ

This is a 2-dimensional real vector

v₁ = 3, v₂ = 4

v ∈ ℝ²

Column Vector Notation

Vectors are typically written as column vectors:

v = ⎡v₁⎤
    ⎢v₂⎥
    ⎢⋮ ⎥
    ⎣vₙ⎦

This notation emphasizes the vertical structure.

Python Implementation

import numpy as np

# Classical real vector
v = np.array([[3], [4]], dtype=float)
print(v)
# Output:
# [[3.]
# [4.]]

Quantum Ket Notation

In quantum computing, we use Dirac notation:

|ψ⟩ = ⎡α⎤
      ⎣β⎦

Where:

  • |ψ⟩ is called a "ket"
  • α, β ∈ ℂ are complex amplitudes
  • Represents a quantum state

Qubit State Example

|ψ⟩ = ⎡1/√2⎤
      ⎣1/√2⎦

This represents an equal superposition state

α = 1/√2, β = 1/√2

Components and Dimension

Dimension

The dimension n is the number of components:

  • 1-qubit system: n = 2 (2D Hilbert space)
  • 2-qubit system: n = 4 (4D Hilbert space)
  • n-qubit system: n = 2ⁿ dimensions

Components

Each component vᵢ can be:

  • Real: vᵢ ∈ ℝ (classical physics)
  • Complex: vᵢ ∈ ℂ (quantum mechanics)

Complex Components

|ψ⟩ = ⎡0.6 + 0.2i⎤
      ⎣0.5 - 0.5i⎦

Both components are complex numbers

This is typical in quantum computing!

Classical vs Quantum Vectors

Classical Vectors (Real)

Velocity Vector:

v = [3, 4]ᵀ m/s

Components: vₓ = 3 m/s, vᵧ = 4 m/s

Magnitude: |v| = 5 m/s

Direction: tan⁻¹(4/3) ≈ 53.1°

import numpy as np

v = np.array([[3], [4]], dtype=float)
magnitude = np.linalg.norm(v)
print(f"Magnitude: {magnitude}") # 5.0

Quantum Vectors (Complex)

Qubit State:

|ψ⟩ = ⎡α⎤
      ⎣β⎦

Components: α, β ∈ ℂ

Normalization: |α|² + |β|² = 1

Probabilities: P(0) = |α|², P(1) = |β|²

import numpy as np

psi = np.array([[1/np.sqrt(2)],
[1/np.sqrt(2)]], dtype=complex)
norm = np.linalg.norm(psi)
print(f"Norm: {norm}") # 1.0

Quantum Interpretation

In quantum computing, vectors have special meaning:

Probability Amplitudes

Each component represents a probability amplitude:

|ψ⟩ = α|0⟩ + β|1⟩

Where:

  • α is the amplitude for state |0⟩
  • β is the amplitude for state |1⟩
  • |α|² is the probability of measuring 0
  • |β|² is the probability of measuring 1

Born Rule

The probability of measuring a state is given by:

P(outcome) = |amplitude|²

Example: Equal Superposition

|+⟩ = ⎡1/√2⎤
      ⎣1/√2⎦

Probabilities:

  • P(0) = |1/√2|² = 1/2 = 50%
  • P(1) = |1/√2|² = 1/2 = 50%

Equal probability of measuring 0 or 1!

import numpy as np

plus = np.array([[1/np.sqrt(2)],
[1/np.sqrt(2)]], dtype=complex)

prob_0 = np.abs(plus[0, 0])**2
prob_1 = np.abs(plus[1, 0])**2

print(f"P(0) = {prob_0:.3f}") # 0.500
print(f"P(1) = {prob_1:.3f}") # 0.500

Basis States

The computational basis states are:

State |0⟩

|0⟩ = ⎡1⎤
      ⎣0⎦

Represents the "zero" state

100% probability of measuring 0

State |1⟩

|1⟩ = ⎡0⎤
      ⎣1⎦

Represents the "one" state

100% probability of measuring 1

General Qubit State

Any qubit state can be written as a linear combination:

|ψ⟩ = α|0⟩ + β|1⟩ = ⎡α⎤
                                ⎣β⎦
import numpy as np

# Basis states
zero = np.array([[1], [0]], dtype=complex)
one = np.array([[0], [1]], dtype=complex)

# General state
alpha = 0.6
beta = 0.8
psi = alpha * zero + beta * one

print("State |ψ⟩:")
print(psi)
# [[0.6]
# [0.8]]

Key Properties

1. Ordered Collection

The order of components matters:

[3, 4]ᵀ ≠ [4, 3]ᵀ

2. Fixed Dimension

All vectors in a space have the same dimension:

  • Cannot add vectors of different dimensions
  • Single qubit: always 2D
  • Two qubits: always 4D

3. Complex Components

Quantum vectors have complex components:

  • Enables phase information
  • Required for quantum interference
  • Essential for quantum algorithms

4. Normalization

Quantum state vectors must be normalized:

||ψ⟩|| = √(|α|² + |β|²) = 1

This ensures total probability = 1
