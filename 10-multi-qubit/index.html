What are Multi-Qubit Systems?

Multi-qubit systems are quantum systems composed of multiple qubits. The state space of a multi-qubit system is formed by taking the tensor product of the individual qubit state spaces.

Key Principle: For n qubits, the combined Hilbert space has dimension 2ⁿ, requiring 2ⁿ basis states to describe all possible states.
Tensor Product:
|ψ⟩ ⊗ |φ⟩ = |ψφ⟩

Tensor Product Basics

The tensor product (⊗) combines two vector spaces into a larger space. For quantum states:

Example: Two Single Qubits

If we have:

Qubit 1: |ψ⟩ = α₀|0⟩ + α₁|1⟩
Qubit 2: |φ⟩ = β₀|0⟩ + β₁|1⟩

The combined two-qubit state is:

|ψ⟩ ⊗ |φ⟩ = (α₀|0⟩ + α₁|1⟩) ⊗ (β₀|0⟩ + β₁|1⟩)
= α₀β₀|00⟩ + α₀β₁|01⟩ + α₁β₀|10⟩ + α₁β₁|11⟩

Tensor Product Properties

  • Bilinearity: (a|ψ⟩ + b|φ⟩) ⊗ |χ⟩ = a(|ψ⟩ ⊗ |χ⟩) + b(|φ⟩ ⊗ |χ⟩)
  • Associativity: (|ψ⟩ ⊗ |φ⟩) ⊗ |χ⟩ = |ψ⟩ ⊗ (|φ⟩ ⊗ |χ⟩)
  • Not Commutative: |ψ⟩ ⊗ |φ⟩ ≠ |φ⟩ ⊗ |ψ⟩ (in general)
  • Dimension: dim(V ⊗ W) = dim(V) × dim(W)

Two-Qubit Basis States

A two-qubit system has 4 computational basis states, formed by tensor products of single-qubit basis states:

|00⟩ = |0⟩ ⊗ |0⟩

[1, 0] ⊗ [1, 0] = [1, 0, 0, 0]ᵀ

Both qubits in state |0⟩

|01⟩ = |0⟩ ⊗ |1⟩

[1, 0] ⊗ [0, 1] = [0, 1, 0, 0]ᵀ

First qubit |0⟩, second qubit |1⟩

|10⟩ = |1⟩ ⊗ |0⟩

[0, 1] ⊗ [1, 0] = [0, 0, 1, 0]ᵀ

First qubit |1⟩, second qubit |0⟩

|11⟩ = |1⟩ ⊗ |1⟩

[0, 1] ⊗ [0, 1] = [0, 0, 0, 1]ᵀ

Both qubits in state |1⟩

Computing Tensor Products

To compute the tensor product of two vectors, we multiply each component of the first vector by the entire second vector:

Example: Tensor Product Calculation

|ψ⟩ = [α₀, α₁]ᵀ
|φ⟩ = [β₀, β₁]ᵀ

|ψ⟩ ⊗ |φ⟩ = [α₀β₀, α₀β₁, α₁β₀, α₁β₁]ᵀ

Concrete Example:

|+⟩ = [1/√2, 1/√2]ᵀ
|0⟩ = [1, 0]ᵀ

|+⟩ ⊗ |0⟩ = [1/√2, 0, 1/√2, 0]ᵀ
= (1/√2)|00⟩ + (1/√2)|10⟩

Entangled vs Separable States

Not all two-qubit states can be written as tensor products of single-qubit states!

Separable State: Can be written as |ψ⟩ ⊗ |φ⟩ for some single-qubit states |ψ⟩ and |φ⟩
Entangled State: Cannot be written as a tensor product of single-qubit states

Example: Separable State

|ψ⟩ = (1/√2)(|00⟩ + |01⟩)
= (1/√2)(|0⟩ ⊗ |0⟩ + |0⟩ ⊗ |1⟩)
= |0⟩ ⊗ (1/√2)(|0⟩ + |1⟩)
= |0⟩ ⊗ |+⟩

This is separable: first qubit is |0⟩, second qubit is |+⟩

Example: Entangled State (Bell State)

|Φ⁺⟩ = (1/√2)(|00⟩ + |11⟩)

This cannot be written as |ψ⟩ ⊗ |φ⟩ for any single-qubit states. The qubits are entangled - measuring one instantly affects the other!

Three-Qubit Systems

For three qubits, the Hilbert space has dimension 2³ = 8, with 8 basis states:

{|000⟩, |001⟩, |010⟩, |011⟩, |100⟩, |101⟩, |110⟩, |111⟩}

A general three-qubit state is:

|ψ⟩ = c₀₀₀|000⟩ + c₀₀₁|001⟩ + c₀₁₀|010⟩ + c₀₁₁|011⟩
+ c₁₀₀|100⟩ + c₁₀₁|101⟩ + c₁₁₀|110⟩ + c₁₁₁|111⟩

where Σ|cᵢⱼₖ|² = 1 (normalization)

Example: GHZ State

|GHZ⟩ = (1/√2)(|000⟩ + |111⟩)

The Greenberger-Horne-Zeilinger (GHZ) state is a maximally entangled three-qubit state. All three qubits are correlated: measuring one affects all others.

Scaling to n Qubits

The power of quantum computing comes from the exponential growth of the state space:

Number of Qubits (n) Hilbert Space Dimension (2ⁿ) Classical Bits Equivalent
1 2 1 bit
2 4 2 bits
3 8 3 bits
10 1,024 10 bits
50 ~10¹⁵ 50 bits
100 ~10³⁰ 100 bits

With just 300 qubits, the state space has more dimensions than there are atoms in the observable universe!

Python Implementation

import numpy as np

# Define single-qubit states
ket0 = np.array([1, 0])
ket1 = np.array([0, 1])
ket_plus = np.array([1, 1]) / np.sqrt(2)

# Compute tensor product
def tensor_product(v1, v2):
    """Compute tensor product of two vectors."""
    return np.kron(v1, v2)

# Two-qubit states
ket00 = tensor_product(ket0, ket0)  # [1, 0, 0, 0]
ket01 = tensor_product(ket0, ket1)  # [0, 1, 0, 0]
ket10 = tensor_product(ket1, ket0)  # [0, 0, 1, 0]
ket11 = tensor_product(ket1, ket1)  # [0, 0, 0, 1]

# Bell state (entangled)
bell_state = (ket00 + ket11) / np.sqrt(2)
print(f"Bell state: {bell_state}")

# Separable state
separable = tensor_product(ket0, ket_plus)
print(f"Separable state: {separable}")

# Three-qubit state
ket000 = tensor_product(tensor_product(ket0, ket0), ket0)
print(f"Three-qubit state |000⟩: {ket000}")

Applications in Quantum Computing

1. Quantum Algorithms

Multi-qubit systems enable quantum algorithms like Shor's algorithm (factoring) and Grover's algorithm (search), which provide exponential or quadratic speedups.

2. Quantum Error Correction

Error correction codes use multiple physical qubits to encode a single logical qubit, protecting against decoherence and errors.

3. Quantum Simulation

Multi-qubit systems can simulate other quantum systems, useful for chemistry, materials science, and physics research.

4. Quantum Communication

Entangled multi-qubit states enable quantum teleportation, superdense coding, and quantum key distribution.

Key Takeaways

  • Multi-qubit systems are formed using tensor products (⊗)
  • n qubits create a 2ⁿ-dimensional Hilbert space
  • Two-qubit systems have 4 basis states: |00⟩, |01⟩, |10⟩, |11⟩
  • Separable states can be factored: |ψ⟩ = |ψ₁⟩ ⊗ |ψ₂⟩
  • Entangled states cannot be factored into single-qubit states
  • Exponential growth of state space enables quantum advantage
  • Tensor products are bilinear and associative but not commutative
