What is the Bloch Sphere?

The Bloch sphere is a geometric representation of the state space of a single qubit. Every pure qubit state corresponds to a unique point on the surface of a unit sphere.

Key Insight: The Bloch sphere provides an intuitive geometric picture of quantum states and operations. Quantum gates become rotations on the sphere!
Bloch Sphere Representation:
|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ) sin(θ/2)|1⟩

where θ ∈ [0, π] and φ ∈ [0, 2π]

Bloch Vector

Any qubit state can be represented as a point on the Bloch sphere using spherical coordinates:

Cartesian Coordinates:
x = sin(θ) cos(φ)
y = sin(θ) sin(φ)
z = cos(θ)

Bloch vector: r⃗ = (x, y, z)

Common States on the Bloch Sphere

  • |0⟩: North pole (θ=0, z=+1)
  • |1⟩: South pole (θ=π, z=-1)
  • |+⟩: Positive x-axis (θ=π/2, φ=0)
  • |−⟩: Negative x-axis (θ=π/2, φ=π)
  • |+i⟩: Positive y-axis (θ=π/2, φ=π/2)
  • |−i⟩: Negative y-axis (θ=π/2, φ=3π/2)

Quantum Gates as Rotations

Quantum gates correspond to rotations on the Bloch sphere. This provides a geometric interpretation of quantum operations.

Pauli Gates

X Gate: 180° rotation around x-axis
|0⟩ → |1⟩ (north pole → south pole)

Y Gate: 180° rotation around y-axis
|0⟩ → i|1⟩

Z Gate: 180° rotation around z-axis
|+⟩ → |−⟩ (positive x → negative x)

Hadamard Gate

H Gate: 180° rotation around axis (x+z)/√2
|0⟩ → |+⟩ (north pole → positive x-axis)
|1⟩ → |−⟩ (south pole → negative x-axis)

Rotation Gates

Rₓ(θ): Rotation by angle θ around x-axis
Rᵧ(θ): Rotation by angle θ around y-axis
Rᵤ(θ): Rotation by angle θ around z-axis

Properties of the Bloch Sphere

1. Pure States

Pure states lie on the surface of the sphere (|r⃗| = 1). The state is completely determined by the direction of the Bloch vector.

2. Mixed States

Mixed states lie inside the sphere (|r⃗| < 1). The maximally mixed state (I/2) is at the center (r⃗ = 0).

3. Orthogonal States

Orthogonal states are antipodal points on the sphere (opposite sides). For example, |0⟩ and |1⟩ are at opposite poles.

4. Global Phase

Global phase factors e^(iα) don't affect the Bloch vector. States that differ only by global phase map to the same point on the sphere.

Measurement on the Bloch Sphere

Measurement in the computational basis projects the state onto the z-axis (|0⟩ or |1⟩).

Measurement Probabilities:
P(0) = |⟨0|ψ⟩|² = cos²(θ/2) = (1 + z)/2
P(1) = |⟨1|ψ⟩|² = sin²(θ/2) = (1 - z)/2

where z = cos(θ) is the z-coordinate

Examples

  • |0⟩ (z=+1): P(0)=1, P(1)=0
  • |1⟩ (z=-1): P(0)=0, P(1)=1
  • |+⟩ (z=0): P(0)=0.5, P(1)=0.5

Limitations of the Bloch Sphere

Single Qubit Only

The Bloch sphere representation only works for single qubits. Multi-qubit states cannot be visualized this way because:

  • Two qubits require a 4-dimensional space (cannot visualize in 3D)
  • Entangled states have no simple geometric representation
  • The state space grows exponentially: 2^n dimensions for n qubits

No Relative Phase Visualization

The Bloch sphere doesn't directly show the relative phase between |0⟩ and |1⟩ components. The phase φ is encoded in the azimuthal angle.

Applications

1. Quantum Algorithm Visualization

Visualize how quantum algorithms manipulate qubit states as trajectories on the Bloch sphere.

2. Gate Optimization

Decompose arbitrary single-qubit gates into sequences of rotations around different axes.

3. Error Analysis

Understand how noise and errors affect quantum states as deviations from intended trajectories on the sphere.

4. Quantum Control

Design control pulses to drive quantum states along specific paths on the Bloch sphere.

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def bloch_vector(theta, phi):
    """Convert spherical to Cartesian coordinates."""
    x = np.sin(theta) * np.cos(phi)
    y = np.sin(theta) * np.sin(phi)
    z = np.cos(theta)
    return np.array([x, y, z])

def state_to_bloch(psi):
    """Convert quantum state to Bloch vector."""
    # psi = [alpha, beta]
    alpha, beta = psi[0], psi[1]
    
    # Remove global phase
    if np.abs(alpha) > 1e-10:
        phase = np.angle(alpha)
        alpha = alpha * np.exp(-1j * phase)
        beta = beta * np.exp(-1j * phase)
    
    # Extract theta and phi
    theta = 2 * np.arccos(np.abs(alpha))
    phi = np.angle(beta) if np.abs(beta) > 1e-10 else 0
    
    return bloch_vector(theta, phi)

# Example: |+⟩ state
ket_plus = np.array([1, 1]) / np.sqrt(2)
bloch_plus = state_to_bloch(ket_plus)
print(f"|+⟩ Bloch vector: {bloch_plus}")

# Plot Bloch sphere
fig = plt.figure(figsize=(10, 10))
ax = fig.add_subplot(111, projection='3d')

# Draw sphere
u = np.linspace(0, 2*np.pi, 100)
v = np.linspace(0, np.pi, 100)
x = np.outer(np.cos(u), np.sin(v))
y = np.outer(np.sin(u), np.sin(v))
z = np.outer(np.ones(np.size(u)), np.cos(v))
ax.plot_surface(x, y, z, alpha=0.1, color='cyan')

# Draw state vector
ax.quiver(0, 0, 0, bloch_plus[0], bloch_plus[1], bloch_plus[2],
          color='red', arrow_length_ratio=0.1, linewidth=3)

ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')
ax.set_title('Bloch Sphere')
plt.show()

Key Takeaways

  • Bloch sphere represents single-qubit states geometrically
  • Pure states lie on the surface, mixed states inside
  • State: |ψ⟩ = cos(θ/2)|0⟩ + e^(iφ) sin(θ/2)|1⟩
  • Quantum gates are rotations on the sphere
  • Orthogonal states are antipodal points
  • Measurement probabilities: P(0) = (1+z)/2, P(1) = (1-z)/2
  • Only works for single qubits (not multi-qubit systems)
  • Provides intuitive visualization of quantum operations
