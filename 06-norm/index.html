Definition

The norm (or magnitude) measures the length of a vector:

||v|| = √(v₁² + v₂² + ... + vₙ²)

For complex vectors:

||v|| = √(|v₁|² + |v₂|² + ... + |vₙ|²)

Example: Real Vector

v = [3, 4]ᵀ

||v|| = √(3² + 4²) = √(9 + 16) = √25 = 5

Normalization

Normalization creates a unit vector (length 1):

v̂ = v / ||v||

The normalized vector v̂ has:

  • Same direction as v
  • Length exactly 1

Example

v = [3, 4]ᵀ, ||v|| = 5

v̂ = [3, 4]ᵀ / 5 = [0.6, 0.8]ᵀ

Check: ||v̂|| = √(0.6² + 0.8²) = √(0.36 + 0.64) = 1 ✓

Python Implementation

import numpy as np

# Real vector
v = np.array([[3], [4]], dtype=float)

# Calculate norm
norm = np.linalg.norm(v)
print(f"||v|| = {norm}")
# Output: 5.0

# Normalize
v_normalized = v / norm
print(f"v̂ = {v_normalized.T[0]}")
# Output: [0.6 0.8]

# Verify
print(f"||v̂|| = {np.linalg.norm(v_normalized)}")
# Output: 1.0

Properties of Norm

1. Non-negativity

||v|| ≥ 0

||v|| = 0 if and only if v = 0

2. Scalar Multiplication

||cv|| = |c| · ||v||

For scalar c

3. Triangle Inequality

||v + w|| ≤ ||v|| + ||w||

Sum of norms ≥ norm of sum

4. Relationship to Inner Product

||v|| = √⟨v|v⟩

Norm from inner product

Quantum State Normalization

In quantum mechanics, all valid states must be normalized!

Normalization Condition

||ψ⟩|| = 1

This ensures total probability = 1

|α|² + |β|² = 1

Example: Normalizing a Quantum State

Given: |ψ⟩ = [3, 4]ᵀ

Step 1: Calculate norm

||ψ⟩|| = √(3² + 4²) = 5

Step 2: Normalize

|ψ̂⟩ = |ψ⟩ / ||ψ⟩|| = [3, 4]ᵀ / 5 = [0.6, 0.8]ᵀ

Step 3: Verify

|0.6|² + |0.8|² = 0.36 + 0.64 = 1 ✓
import numpy as np

psi = np.array([[3], [4]], dtype=complex)
norm = np.linalg.norm(psi)

psi_normalized = psi / norm

# Verify probabilities sum to 1
prob_sum = np.sum(np.abs(psi_normalized)**2)
print(f"Total probability: {prob_sum:.4f}") # 1.0000

Complex Vector Normalization

Example 1: Complex Components

|ψ⟩ = [1+i, 2-i]ᵀ

Calculate norm:

||ψ⟩|| = √(|1+i|² + |2-i|²)
= √((1² + 1²) + (2² + (-1)²))
= √(2 + 5) = √7 ≈ 2.646

Normalized:

|ψ̂⟩ = [(1+i)/√7, (2-i)/√7]ᵀ

Example 2: Pure Phase

|ψ⟩ = [e^(iπ/4), e^(iπ/2)]ᵀ

Calculate norm:

||ψ⟩|| = √(|e^(iπ/4)|² + |e^(iπ/2)|²)
= √(1 + 1) = √2

Normalized:

|ψ̂⟩ = [e^(iπ/4)/√2, e^(iπ/2)/√2]ᵀ

Common Quantum States

Computational Basis

|0⟩ = [1, 0]ᵀ

||0⟩|| = 1 ✓

|1⟩ = [0, 1]ᵀ

||1⟩|| = 1 ✓

Superposition States

|+⟩ = (1/√2)[1, 1]ᵀ

||+⟩|| = 1 ✓

|-⟩ = (1/√2)[1, -1]ᵀ

||-⟩|| = 1 ✓

General Qubit

|ψ⟩ = α|0⟩ + β|1⟩

where |α|² + |β|² = 1

||ψ⟩|| = 1 ✓

Bell State

|Φ⁺⟩ = (1/√2)(|00⟩ + |11⟩)

||Φ⁺⟩|| = 1 ✓

Distance Between Vectors

The norm defines distance in vector space:

d(v, w) = ||v - w||

Example

v = [3, 4]ᵀ, w = [1, 2]ᵀ

Difference:

v - w = [2, 2]ᵀ

Distance:

d(v, w) = ||[2, 2]ᵀ|| = √(4 + 4) = √8 ≈ 2.828

Quantum State Distance

Distance between quantum states |ψ⟩ and |φ⟩:

d(ψ, φ) = ||ψ⟩ - |φ⟩||

Measures how different two quantum states are

Unit Vectors

A unit vector has norm 1:

||v̂|| = 1

Standard Unit Vectors

In 2D:

  • ê₁ = [1, 0]ᵀ (x-direction)
  • ê₂ = [0, 1]ᵀ (y-direction)

In 3D:

  • ê₁ = [1, 0, 0]ᵀ (x-direction)
  • ê₂ = [0, 1, 0]ᵀ (y-direction)
  • ê₃ = [0, 0, 1]ᵀ (z-direction)

Creating Unit Vector in Any Direction

Given direction v, create unit vector:

v̂ = v / ||v||

Example: v = [3, 4]ᵀ

v̂ = [3, 4]ᵀ / 5 = [0.6, 0.8]ᵀ

Points in same direction, but length 1

Applications

1. Quantum State Preparation

Always normalize states before use:

|ψ⟩ → |ψ⟩ / ||ψ⟩||

2. Probability Calculation

Normalized states ensure valid probabilities:

Σᵢ |αᵢ|² = 1

3. Direction Vectors

Unit vectors specify direction without magnitude

4. Orthonormal Bases

Basis vectors must be normalized:

||eᵢ|| = 1 for all i
