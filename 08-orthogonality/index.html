Definition

Two vectors are orthogonal if their inner product is zero:

⟨v|w⟩ = 0

For real vectors:

v · w = v₁w₁ + v₂w₂ + ... + vₙwₙ = 0

For complex vectors:

⟨v|w⟩ = v₁*w₁ + v₂*w₂ + ... + vₙ*wₙ = 0
Geometric Interpretation: Orthogonal vectors are perpendicular (90° angle)

Computational Basis Orthogonality

The computational basis states are orthogonal:

|0⟩ = [1, 0]ᵀ
|1⟩ = [0, 1]ᵀ

Verify orthogonality:

⟨0|1⟩ = 1* · 0 + 0* · 1 = 0 ✓

Example: Python Verification

import numpy as np

zero = np.array([1, 0])
one = np.array([0, 1])

inner_product = np.vdot(zero, one)
print(f"⟨0|1⟩ = {inner_product}") # 0

# Check orthogonality
is_orthogonal = np.isclose(inner_product, 0)
print(f"Orthogonal: {is_orthogonal}") # True

Hadamard Basis Orthogonality

The Hadamard basis states are also orthogonal:

|+⟩ = (1/√2)[1, 1]ᵀ
|-⟩ = (1/√2)[1, -1]ᵀ

Verify orthogonality:

⟨+|-⟩ = (1/√2)* · (1/√2) + (1/√2)* · (-1/√2)
= 1/2 - 1/2 = 0 ✓

Example: Python Verification

plus = (1/np.sqrt(2)) * np.array([1, 1])
minus = (1/np.sqrt(2)) * np.array([1, -1])

inner_product = np.vdot(plus, minus)
print(f"⟨+|-⟩ = {inner_product:.4f}") # 0.0000

is_orthogonal = np.isclose(inner_product, 0)
print(f"Orthogonal: {is_orthogonal}") # True

Orthonormality

A set of vectors is orthonormal if:

  • All pairs are orthogonal: ⟨vᵢ|vⱼ⟩ = 0 for i ≠ j
  • All vectors are normalized: ⟨vᵢ|vᵢ⟩ = 1

Compact notation:

⟨vᵢ|vⱼ⟩ = δᵢⱼ

where δᵢⱼ is the Kronecker delta (1 if i=j, 0 otherwise)

Computational Basis is Orthonormal

⟨0|0⟩ = 1 ✓ (normalized)

⟨1|1⟩ = 1 ✓ (normalized)

⟨0|1⟩ = 0 ✓ (orthogonal)

⟨1|0⟩ = 0 ✓ (orthogonal)

Quantum Interpretation

Mutually Exclusive Outcomes

Orthogonal quantum states represent mutually exclusive measurement outcomes:

  • If a qubit is in state |0⟩, measuring it will never yield |1⟩
  • If a qubit is in state |1⟩, measuring it will never yield |0⟩
Physical Meaning: Measuring one orthogonal state eliminates the possibility of the other

Distinguishability

Orthogonal states can be perfectly distinguished by measurement:

  • |0⟩ and |1⟩ can be perfectly distinguished
  • |+⟩ and |-⟩ can be perfectly distinguished
  • Non-orthogonal states cannot be perfectly distinguished

Properties of Orthogonal Vectors

1. Pythagorean Theorem

For orthogonal vectors v and w:

||v + w||² = ||v||² + ||w||²

2. Independence

Orthogonal vectors are linearly independent

3. Projection

The projection of v onto orthogonal w is zero:

proj_w(v) = (⟨v|w⟩/⟨w|w⟩)w = 0

4. Decomposition

Any vector can be uniquely decomposed into orthogonal components

Examples

Example 1: Classical 2D Vectors

v = [3, 0], w = [0, 4]

v · w = 3·0 + 0·4 = 0 ✓

These vectors are orthogonal (perpendicular)

Example 2: Classical 3D Vectors

v = [1, 0, 0], w = [0, 1, 0]

v · w = 1·0 + 0·1 + 0·0 = 0 ✓

Standard basis vectors are orthogonal

Example 3: Non-Orthogonal Quantum States

|0⟩ = [1, 0]ᵀ, |+⟩ = [1/√2, 1/√2]ᵀ

⟨0|+⟩ = 1·(1/√2) + 0·(1/√2) = 1/√2 ≠ 0

These states are NOT orthogonal

Angle: θ = arccos(1/√2) = 45°

Example 4: Complex Orthogonal Vectors

v = [1, i], w = [i, 1]

⟨v|w⟩ = 1*·i + i*·1 = -i + i = 0 ✓

These complex vectors are orthogonal

Gram-Schmidt Orthogonalization

Process to convert any set of linearly independent vectors into an orthonormal set:

Algorithm:

  1. Start with first vector: u₁ = v₁/||v₁||
  2. For each subsequent vector vₖ:
    • Subtract projections onto previous vectors
    • Normalize the result
uₖ = (vₖ - Σⱼ₌₁ᵏ⁻¹ ⟨vₖ|uⱼ⟩uⱼ) / ||vₖ - Σⱼ₌₁ᵏ⁻¹ ⟨vₖ|uⱼ⟩uⱼ||

Example: Orthogonalize Two Vectors

Given: v₁ = [1, 1], v₂ = [1, 0]

Step 1: Normalize v₁

u₁ = v₁/||v₁|| = [1/√2, 1/√2]

Step 2: Remove projection of v₂ onto u₁

v₂' = v₂ - ⟨v₂|u₁⟩u₁
= [1, 0] - (1/√2)[1/√2, 1/√2]
= [1/2, -1/2]

Step 3: Normalize

u₂ = v₂'/||v₂'|| = [1/√2, -1/√2]

Result: {u₁, u₂} is orthonormal

Applications

1. Quantum Measurement

Measurement bases consist of orthogonal states

  • Computational basis: {|0⟩, |1⟩}
  • Hadamard basis: {|+⟩, |-⟩}

2. Quantum Error Correction

Error syndromes are detected using orthogonal subspaces

3. Quantum Cryptography

BB84 protocol uses two orthogonal bases for secure key distribution

4. State Discrimination

Orthogonal states can be perfectly distinguished, non-orthogonal cannot

5. Hilbert Space Structure

Orthonormal bases provide coordinate systems for quantum states

Testing Orthogonality

Method 1: Inner Product

Compute ⟨v|w⟩ and check if it equals zero

Method 2: Angle

Compute angle θ = arccos(⟨v|w⟩/(||v|| ||w||))

Orthogonal if θ = 90° = π/2 radians

Method 3: Pythagorean Theorem

Check if ||v + w||² = ||v||² + ||w||²

Python Implementation

def are_orthogonal(v, w, tolerance=1e-10):
"""Check if two vectors are orthogonal"""
inner_prod = np.vdot(v, w)
return np.abs(inner_prod) < tolerance

# Test
v = np.array([1, 0])
w = np.array([0, 1])
print(are_orthogonal(v, w)) # True

v = np.array([1, 1])
w = np.array([1, 0])
print(are_orthogonal(v, w)) # False
