🔗 Linear Independence

Foundation of Basis Vectors and Quantum States

Definition

A set of vectors {v₁, v₂, ..., vₙ} is linearly independent if:

c₁v₁ + c₂v₂ + ... + cₙvₙ = 0

implies that all coefficients are zero:

c₁ = c₂ = ... = cₙ = 0
Intuition: No vector can be written as a linear combination of the others

Linear Dependence

Vectors are linearly dependent if at least one can be written as a combination of others:

v₃ = c₁v₁ + c₂v₂

Examples

Example 1: Independent Vectors

v₁ = [1, 0], v₂ = [0, 1]

These are linearly independent because:

c₁[1, 0] + c₂[0, 1] = [0, 0]

only when c₁ = 0 and c₂ = 0

Example 2: Dependent Vectors

v₁ = [1, 0], v₂ = [2, 0]

These are linearly dependent because:

v₂ = 2v₁

or equivalently: 2v₁ - v₂ = 0

Example 3: Three Vectors in 2D

v₁ = [1, 0], v₂ = [0, 1], v₃ = [1, 1]

These are linearly dependent because:

v₃ = v₁ + v₂

Any 3 vectors in 2D space must be dependent!

Quantum Basis Independence

Computational Basis

The computational basis states are linearly independent:

|0⟩ = [1, 0]ᵀ, |1⟩ = [0, 1]ᵀ

Proof: If c₁|0⟩ + c₂|1⟩ = 0, then:

c₁[1, 0]ᵀ + c₂[0, 1]ᵀ = [c₁, c₂]ᵀ = [0, 0]ᵀ

Therefore c₁ = 0 and c₂ = 0 ✓

Quantum Implication: Any qubit state can be uniquely represented as |ψ⟩ = α|0⟩ + β|1⟩

Python Implementation

import numpy as np

def are_linearly_independent(vectors):
"""Check if vectors are linearly independent"""
# Create matrix with vectors as columns
matrix = np.column_stack(vectors)

# Compute rank
rank = np.linalg.matrix_rank(matrix)

# Independent if rank equals number of vectors
return rank == len(vectors)

# Test with computational basis
zero = np.array([1, 0])
one = np.array([0, 1])

print(are_linearly_independent([zero, one]))
# Output: True

Testing Linear Independence

Method 1: Matrix Rank

Create a matrix with vectors as columns and compute rank:

  • If rank = number of vectors → Independent
  • If rank < number of vectors → Dependent

Method 2: Determinant (Square Matrices)

For n vectors in n-dimensional space:

  • If det(M) ≠ 0 → Independent
  • If det(M) = 0 → Dependent

Method 3: Row Reduction

Perform Gaussian elimination:

  • If no row becomes all zeros → Independent
  • If a row becomes all zeros → Dependent

Example: Testing with Rank

Vectors: v₁ = [1, 0], v₂ = [0, 1], v₃ = [1, 1]

Matrix M = [[1, 0, 1], [0, 1, 1]]

Rank(M) = 2

Number of vectors = 3

Since 2 < 3, vectors are dependent ✓

Properties

1. Maximum Independent Vectors

In n-dimensional space, at most n vectors can be linearly independent

  • 2D space: max 2 independent vectors
  • 3D space: max 3 independent vectors
  • n-qubit system (2ⁿ dimensions): max 2ⁿ independent vectors

2. Subset Property

Any subset of independent vectors is also independent

3. Extension Property

Independent vectors can be extended to a basis

4. Orthogonal Implies Independent

If vectors are orthogonal (and non-zero), they are linearly independent

But independent vectors need not be orthogonal!

Span and Basis

Span

The span of vectors {v₁, v₂, ..., vₙ} is the set of all linear combinations:

span{v₁, v₂, ..., vₙ} = {c₁v₁ + c₂v₂ + ... + cₙvₙ : cᵢ ∈ ℂ}

Basis

A basis is a set of vectors that is:

  • Linearly independent
  • Spans the entire space

Computational Basis is a Basis

{|0⟩, |1⟩} is a basis for single-qubit states because:

  1. Linearly independent ✓
  2. Spans all qubit states: any |ψ⟩ = α|0⟩ + β|1⟩ ✓

Multi-Qubit Independence

Two-Qubit Basis

The four states {|00⟩, |01⟩, |10⟩, |11⟩} are linearly independent:

|00⟩ = [1, 0, 0, 0]ᵀ
|01⟩ = [0, 1, 0, 0]ᵀ
|10⟩ = [0, 0, 1, 0]ᵀ
|11⟩ = [0, 0, 0, 1]ᵀ

Any two-qubit state can be uniquely written as:

|ψ⟩ = α|00⟩ + β|01⟩ + γ|10⟩ + δ|11⟩

Bell States

The four Bell states also form a basis (linearly independent):

|Φ⁺⟩ = (|00⟩ + |11⟩)/√2
|Φ⁻⟩ = (|00⟩ - |11⟩)/√2
|Ψ⁺⟩ = (|01⟩ + |10⟩)/√2
|Ψ⁻⟩ = (|01⟩ - |10⟩)/√2

Applications

1. Quantum State Representation

Independent basis vectors ensure unique state representation

2. Quantum Algorithms

Algorithm correctness relies on basis independence

3. Quantum Error Correction

Error syndromes use independent subspaces

4. Dimension Counting

Number of independent vectors = dimension of space

  • Single qubit: 2 independent states
  • Two qubits: 4 independent states
  • n qubits: 2ⁿ independent states

5. Completeness Relations

Independent basis vectors satisfy:

Σᵢ |bᵢ⟩⟨bᵢ| = I

Common Mistakes

Mistake 1: Confusing Independence with Orthogonality

❌ Independent vectors must be orthogonal

✓ Independent vectors need not be orthogonal

Example: v₁ = [1, 0], v₂ = [1, 1] are independent but not orthogonal

Mistake 2: Too Many Vectors

❌ Can have 3 independent vectors in 2D space

✓ At most n independent vectors in n-dimensional space

Mistake 3: Zero Vector

❌ Any set containing the zero vector is independent

✓ Any set containing the zero vector is dependent

Because: 1·0 + 0·v₁ + 0·v₂ = 0 with non-zero coefficient
