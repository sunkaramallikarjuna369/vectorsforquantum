Definition

A basis is a set of linearly independent vectors that span the entire vector space.

Properties of a Basis

  • Linearly independent
  • Spans the entire space
  • Any vector can be written as a linear combination
  • Number of basis vectors = dimension of space

Example: 2D Space

Standard basis: {ê₁, ê₂}

ê₁ = [1, 0]ᵀ, ê₂ = [0, 1]ᵀ

Any 2D vector v = [x, y]ᵀ can be written as:

v = x·ê₁ + y·ê₂

Classical Basis Vectors

2D Standard Basis

î = [1, 0]ᵀ (x-direction)
ĵ = [0, 1]ᵀ (y-direction)

3D Standard Basis

î = [1, 0, 0]ᵀ (x-direction)
ĵ = [0, 1, 0]ᵀ (y-direction)
k̂ = [0, 0, 1]ᵀ (z-direction)

Example: Vector in 3D

v = [3, 4, 5]ᵀ

v = 3î + 4ĵ + 5k̂

Quantum Basis States

Computational Basis

The standard basis for qubits:

|0⟩ = [1, 0]ᵀ
|1⟩ = [0, 1]ᵀ

Any qubit state can be written as:

|ψ⟩ = α|0⟩ + β|1⟩

where |α|² + |β|² = 1

Example: Superposition State

|+⟩ = (1/√2)|0⟩ + (1/√2)|1⟩

= (1/√2)[1, 0]ᵀ + (1/√2)[0, 1]ᵀ
= [1/√2, 1/√2]ᵀ

Python Implementation

import numpy as np

# Computational basis states
zero = np.array([[1], [0]], dtype=complex)
one = np.array([[0], [1]], dtype=complex)

# Create superposition
alpha = 0.6
beta = 0.8
psi = alpha * zero + beta * one

print(f"|ψ⟩ = {psi.T[0]}")
# Output: [0.6+0.j 0.8+0.j]

# Verify normalization
norm = np.linalg.norm(psi)
print(f"||ψ⟩|| = {norm:.4f}") # 1.0000

Alternative Bases

Hadamard Basis (|+⟩/|-⟩)

|+⟩ = (1/√2)(|0⟩ + |1⟩) = [1/√2, 1/√2]ᵀ
|-⟩ = (1/√2)(|0⟩ - |1⟩) = [1/√2, -1/√2]ᵀ

Any qubit can also be written in this basis:

|ψ⟩ = γ|+⟩ + δ|-⟩

Example: |0⟩ in Hadamard Basis

|0⟩ = (1/√2)|+⟩ + (1/√2)|-⟩

Verify:

(1/√2)|+⟩ + (1/√2)|-⟩
= (1/√2)·(1/√2)(|0⟩ + |1⟩) + (1/√2)·(1/√2)(|0⟩ - |1⟩)
= (1/2)|0⟩ + (1/2)|1⟩ + (1/2)|0⟩ - (1/2)|1⟩
= |0⟩ ✓

Circular Basis (|R⟩/|L⟩)

|R⟩ = (1/√2)(|0⟩ + i|1⟩)
|L⟩ = (1/√2)(|0⟩ - i|1⟩)

Basis Representation

Given a basis {|b₁⟩, |b₂⟩, ...}, any vector |ψ⟩ can be written as:

|ψ⟩ = Σᵢ cᵢ|bᵢ⟩

The coefficients cᵢ are found using inner products:

cᵢ = ⟨bᵢ|ψ⟩

Example: Finding Coefficients

Given |ψ⟩ = [1/√2, 1/√2]ᵀ, find representation in computational basis

Coefficient for |0⟩:

α = ⟨0|ψ⟩ = 1/√2

Coefficient for |1⟩:

β = ⟨1|ψ⟩ = 1/√2

Therefore:

|ψ⟩ = (1/√2)|0⟩ + (1/√2)|1⟩ = |+⟩

Change of Basis

Converting between different bases:

From Computational to Hadamard Basis

|0⟩ = (1/√2)|+⟩ + (1/√2)|-⟩
|1⟩ = (1/√2)|+⟩ - (1/√2)|-⟩

From Hadamard to Computational Basis

|+⟩ = (1/√2)|0⟩ + (1/√2)|1⟩
|-⟩ = (1/√2)|0⟩ - (1/√2)|1⟩

Example: Change of Basis

Given |ψ⟩ = 0.6|0⟩ + 0.8|1⟩ in computational basis

Express in Hadamard basis:

Substitute basis expressions:

|ψ⟩ = 0.6[(1/√2)|+⟩ + (1/√2)|-⟩] + 0.8[(1/√2)|+⟩ - (1/√2)|-⟩]

Collect terms:

= [(0.6 + 0.8)/√2]|+⟩ + [(0.6 - 0.8)/√2]|-⟩
= (1.4/√2)|+⟩ - (0.2/√2)|-⟩

Multi-Qubit Bases

Two-Qubit Computational Basis

For 2 qubits, the basis has 4 states:

|00⟩ = [1, 0, 0, 0]ᵀ
|01⟩ = [0, 1, 0, 0]ᵀ
|10⟩ = [0, 0, 1, 0]ᵀ
|11⟩ = [0, 0, 0, 1]ᵀ

Any 2-qubit state:

|ψ⟩ = α|00⟩ + β|01⟩ + γ|10⟩ + δ|11⟩

where |α|² + |β|² + |γ|² + |δ|² = 1

Example: Bell State

|Φ⁺⟩ = (1/√2)|00⟩ + (1/√2)|11⟩

= [1/√2, 0, 0, 1/√2]ᵀ

Orthonormal Basis

A basis is orthonormal if:

  • All basis vectors are normalized: ⟨bᵢ|bᵢ⟩ = 1
  • All pairs are orthogonal: ⟨bᵢ|bⱼ⟩ = 0 for i ≠ j
⟨bᵢ|bⱼ⟩ = δᵢⱼ

Computational Basis is Orthonormal

⟨0|0⟩ = 1 ✓

⟨1|1⟩ = 1 ✓

⟨0|1⟩ = 0 ✓

⟨1|0⟩ = 0 ✓

Hadamard Basis is Orthonormal

⟨+|+⟩ = 1 ✓

⟨-|-⟩ = 1 ✓

⟨+|-⟩ = 0 ✓

⟨-|+⟩ = 0 ✓

Applications

1. State Representation

Express quantum states in different bases for different purposes

2. Measurement

Measurement outcomes correspond to basis states

  • Computational basis: measure |0⟩ or |1⟩
  • Hadamard basis: measure |+⟩ or |-⟩

3. Quantum Algorithms

Different algorithms work in different bases:

  • Deutsch-Jozsa: uses Hadamard basis
  • Grover: amplitude amplification in computational basis

4. Quantum Error Correction

Encode information across multiple basis states
