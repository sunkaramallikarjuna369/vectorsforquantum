Vector Addition

To add two vectors, add their corresponding components:

v + w = [v₁ + w₁, v₂ + w₂, ..., vₙ + wₙ]ᵀ

Example

v = [3, 4]ᵀ, w = [1, -2]ᵀ

v + w = [3+1, 4+(-2)]ᵀ = [4, 2]ᵀ

Properties

  • Commutative: v + w = w + v
  • Associative: (u + v) + w = u + (v + w)
  • Identity: v + 0 = v
  • Inverse: v + (-v) = 0

Vector Subtraction

To subtract vectors, subtract their corresponding components:

v - w = [v₁ - w₁, v₂ - w₂, ..., vₙ - wₙ]ᵀ

Example

v = [3, 4]ᵀ, w = [1, -2]ᵀ

v - w = [3-1, 4-(-2)]ᵀ = [2, 6]ᵀ

Relationship to Addition

Subtraction is addition of the negative:

v - w = v + (-w)

Geometric Interpretation

Vector addition follows the parallelogram rule:

Tip-to-Tail Method

  1. Place the tail of w at the tip of v
  2. The sum v + w goes from the tail of v to the tip of w

Parallelogram Method

  1. Place both vectors at the origin
  2. Complete the parallelogram
  3. The diagonal is v + w

Python Implementation

import numpy as np

# Define vectors
v = np.array([[3], [4]], dtype=float)
w = np.array([[1], [-2]], dtype=float)

# Addition
sum_vec = v + w
print(f"v + w = {sum_vec.T[0]}")
# Output: [4. 2.]

# Subtraction
diff_vec = v - w
print(f"v - w = {diff_vec.T[0]}")
# Output: [2. 6.]

Quantum Superposition

In quantum computing, vector addition represents superposition!

Superposition Principle

If |ψ₁⟩ and |ψ₂⟩ are valid quantum states, then any linear combination is also valid:

|ψ⟩ = α|ψ₁⟩ + β|ψ₂⟩

Where α, β ∈ ℂ and |α|² + |β|² = 1

Example: |+⟩ State

The |+⟩ state is a superposition of |0⟩ and |1⟩:

|+⟩ = (1/√2)|0⟩ + (1/√2)|1⟩

This is vector addition with coefficients!

import numpy as np

# Basis states
zero = np.array([[1], [0]], dtype=complex)
one = np.array([[0], [1]], dtype=complex)

# Superposition
plus = (1/np.sqrt(2)) * zero + (1/np.sqrt(2)) * one
print(f"|+⟩ = {plus.T[0]}")
# Output: [0.707+0.j 0.707+0.j]

Physical Meaning

Superposition means the qubit exists in both states simultaneously:

  • Not "either |0⟩ or |1⟩"
  • But "both |0⟩ and |1⟩ at the same time"
  • Measurement collapses to one state
  • Probabilities determined by amplitudes

Quantum Examples

Example 1: Equal Superposition

|ψ⟩ = (1/√2)|0⟩ + (1/√2)|1⟩

Result: [0.707, 0.707]ᵀ

Probabilities: P(0) = 50%, P(1) = 50%

Example 2: Unequal Superposition

|ψ⟩ = (1/2)|0⟩ + (√3/2)|1⟩

Result: [0.5, 0.866]ᵀ

Probabilities: P(0) = 25%, P(1) = 75%

Example 3: With Phase

|ψ⟩ = (1/√2)|0⟩ + (i/√2)|1⟩

Result: [0.707, 0.707i]ᵀ

Probabilities: P(0) = 50%, P(1) = 50%

But different phase!

Example 4: Minus State

|-⟩ = (1/√2)|0⟩ - (1/√2)|1⟩

Result: [0.707, -0.707]ᵀ

Probabilities: P(0) = 50%, P(1) = 50%

Relative phase of π

Multi-Qubit Addition

Vector addition works for multi-qubit systems too!

Two-Qubit Example

Bell state (entangled superposition):

|Φ⁺⟩ = (1/√2)|00⟩ + (1/√2)|11⟩
import numpy as np

# Basis states
zero = np.array([[1], [0]], dtype=complex)
one = np.array([[0], [1]], dtype=complex)

# Two-qubit basis states
state_00 = np.kron(zero, zero) # [1,0,0,0]
state_11 = np.kron(one, one) # [0,0,0,1]

# Bell state (vector addition!)
bell = (1/np.sqrt(2)) * state_00 + (1/np.sqrt(2)) * state_11
print(f"|Φ⁺⟩ = {bell.T[0]}")
# Output: [0.707 0. 0. 0.707]

This creates an entangled state that cannot be separated!

Key Properties

1. Component-wise Operation

Addition/subtraction happens component by component

[v₁, v₂]ᵀ + [w₁, w₂]ᵀ = [v₁+w₁, v₂+w₂]ᵀ

2. Dimension Requirement

Can only add vectors of the same dimension!

  • ✓ [3, 4]ᵀ + [1, -2]ᵀ = [4, 2]ᵀ (both 2D)
  • ✗ [3, 4]ᵀ + [1, -2, 5]ᵀ (different dimensions!)

3. Preserves Vector Space

Sum of two vectors is also a vector in the same space

  • v, w ∈ ℝⁿ ⟹ v + w ∈ ℝⁿ
  • |ψ₁⟩, |ψ₂⟩ ∈ ℂⁿ ⟹ α|ψ₁⟩ + β|ψ₂⟩ ∈ ℂⁿ

4. Normalization Note

For quantum states, the sum may need renormalization:

|ψ⟩ = (α|ψ₁⟩ + β|ψ₂⟩) / ||α|ψ₁⟩ + β|ψ₂⟩||
