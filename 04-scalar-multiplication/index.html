✖️ Scalar Multiplication

Scaling Vectors and Quantum Phase Shifts

Interactive Scalar Multiplication

Adjust the scalar to see how it scales the vector:

Definition

Scalar multiplication multiplies each component by a scalar:

c · v = [c·v₁, c·v₂, ..., c·vₙ]ᵀ

Where c is a scalar (real or complex number)

Example: Real Scalar

v = [3, 4]ᵀ, c = 2

2v = [2·3, 2·4]ᵀ = [6, 8]ᵀ

The vector is scaled by factor of 2

Properties

1. Distributive over Vector Addition

c(v + w) = cv + cw

2. Distributive over Scalar Addition

(c + d)v = cv + dv

3. Associative

c(dv) = (cd)v

4. Identity

1·v = v

Geometric Interpretation

Scalar multiplication scales the vector:

  • c > 1: Stretches the vector
  • 0 < c < 1: Shrinks the vector
  • c = 0: Results in zero vector
  • c < 0: Reverses direction

Examples

v = [3, 4]ᵀ

  • 2v = [6, 8]ᵀ (stretched)
  • 0.5v = [1.5, 2]ᵀ (shrunk)
  • -1v = [-3, -4]ᵀ (reversed)
  • 0v = [0, 0]ᵀ (zero vector)

Python Implementation

import numpy as np

# Define vector
v = np.array([[3], [4]], dtype=float)

# Scalar multiplication
c = 2
scaled = c * v

print(f"v = {v.T[0]}")
print(f"{c}v = {scaled.T[0]}")
# Output: [6. 8.]

Complex Scalar Multiplication

In quantum computing, scalars can be complex numbers!

Complex Phase

Multiplying by a complex phase e^(iφ) changes the phase:

e^(iφ) · |ψ⟩

Example: Phase Shift

|ψ⟩ = [1/√2, 1/√2]ᵀ

Multiply by e^(iπ) = -1:

e^(iπ)|ψ⟩ = [-1/√2, -1/√2]ᵀ

This is a global phase shift of π

import numpy as np

psi = np.array([[1/np.sqrt(2)], [1/np.sqrt(2)]], dtype=complex)
phase = np.exp(1j * np.pi) # e^(iπ) = -1

psi_shifted = phase * psi
print(f"Phase-shifted: {psi_shifted.T[0]}")
# Output: [-0.707-0.j -0.707-0.j]

Quantum Interpretation

Global Phase

Multiplying entire state by a phase doesn't change measurement outcomes:

|ψ⟩ and e^(iφ)|ψ⟩ are physically equivalent

Because probabilities depend on |amplitude|²

Example: Global Phase Invariance

|ψ⟩ = [0.6, 0.8]ᵀ

P(0) = |0.6|² = 0.36

P(1) = |0.8|² = 0.64

e^(iπ/4)|ψ⟩ = [0.6e^(iπ/4), 0.8e^(iπ/4)]ᵀ

P(0) = |0.6e^(iπ/4)|² = |0.6|² = 0.36 (same!)

P(1) = |0.8e^(iπ/4)|² = |0.8|² = 0.64 (same!)

Relative Phase

But relative phases between components matter!

|ψ⟩ = α|0⟩ + β|1⟩ ≠ α|0⟩ + e^(iφ)β|1⟩

Example: Relative Phase Matters

|+⟩ = (1/√2)|0⟩ + (1/√2)|1⟩

|-⟩ = (1/√2)|0⟩ - (1/√2)|1⟩

= (1/√2)|0⟩ + e^(iπ)(1/√2)|1⟩

Both have same measurement probabilities:

  • P(0) = 50%, P(1) = 50%

But they are different quantum states!

  • Different behavior under quantum gates
  • Different interference patterns

Quantum Examples

Example 1: Scaling Amplitude

2|ψ⟩ where |ψ⟩ = [0.3, 0.4]ᵀ

Result: [0.6, 0.8]ᵀ

Note: Need to renormalize!

Normalized: [0.6, 0.8]ᵀ (already normalized)

Example 2: Phase Rotation

e^(iπ/2)|ψ⟩ = i|ψ⟩

|ψ⟩ = [1/√2, 1/√2]ᵀ

i|ψ⟩ = [i/√2, i/√2]ᵀ

Global phase shift of π/2

Example 3: Negative Scalar

-|ψ⟩ = e^(iπ)|ψ⟩

|ψ⟩ = [0.6, 0.8]ᵀ

-|ψ⟩ = [-0.6, -0.8]ᵀ

Global phase shift of π

Example 4: Complex Scalar

(1+i)|ψ⟩

|ψ⟩ = [1, 0]ᵀ

(1+i)|ψ⟩ = [1+i, 0]ᵀ

Magnitude: √2, Phase: π/4

Normalization After Scaling

After scalar multiplication, quantum states may need renormalization:

|ψ'⟩ = (c|ψ⟩) / ||c|ψ⟩||

Example

|ψ⟩ = [0.6, 0.8]ᵀ (normalized)

c = 2

2|ψ⟩ = [1.2, 1.6]ᵀ

||2|ψ⟩|| = 2.0 (not normalized!)

Normalized:

|ψ'⟩ = [1.2, 1.6]ᵀ / 2.0 = [0.6, 0.8]ᵀ

Back to original (for real positive scalar)

import numpy as np

psi = np.array([[0.6], [0.8]], dtype=complex)
c = 2

scaled = c * psi
print(f"Scaled: {scaled.T[0]}")
print(f"Norm: {np.linalg.norm(scaled):.3f}")

normalized = scaled / np.linalg.norm(scaled)
print(f"Normalized: {normalized.T[0]}")
print(f"Norm: {np.linalg.norm(normalized):.3f}")

Applications in Quantum Computing

1. Phase Gates

Phase gates multiply basis states by complex phases:

P(φ)|1⟩ = e^(iφ)|1⟩

2. Amplitude Amplification

Grover's algorithm uses amplitude amplification:

  • Increase amplitude of target states
  • Decrease amplitude of non-target states

3. State Preparation

Prepare states with specific amplitudes:

|ψ⟩ = α|0⟩ + β|1⟩

Where α and β are chosen for desired probabilities

4. Quantum Interference

Relative phases create interference:

  • Constructive interference: phases align
  • Destructive interference: phases cancel

Key Properties

1. Linearity

Scalar multiplication is linear:

c(αv + βw) = cαv + cβw

2. Magnitude Scaling

For real scalar c:

||cv|| = |c| · ||v||

3. Direction Preservation

For positive real scalar c > 0:

  • Direction preserved
  • Only magnitude changes

4. Complex Phase

For complex scalar c = |c|e^(iφ):

  • Magnitude scaled by |c|
  • Phase rotated by φ
