Definition

The inner product (or dot product) measures similarity between vectors:

Real Vectors

v · w = v₁w₁ + v₂w₂ + ... + vₙwₙ

Complex Vectors (Quantum)

⟨v|w⟩ = v₁*w₁ + v₂*w₂ + ... + vₙ*wₙ

Where * denotes complex conjugate

Example: Real Vectors

v = [3, 4]ᵀ, w = [1, 2]ᵀ

v · w = (3)(1) + (4)(2) = 3 + 8 = 11

Bra-Ket Notation

In quantum computing, we use Dirac's bra-ket notation:

  • Ket: |ψ⟩ is a column vector
  • Bra: ⟨ψ| is a row vector (conjugate transpose)
  • Inner Product: ⟨ψ|φ⟩
⟨ψ|φ⟩ = ψ₁*φ₁ + ψ₂*φ₂ + ... + ψₙ*φₙ

Example

|ψ⟩ = [1/√2, 1/√2]ᵀ

|φ⟩ = [1, 0]ᵀ

⟨ψ|φ⟩ = (1/√2)*(1) + (1/√2)*(0) = 1/√2

Geometric Interpretation

The inner product relates to the angle between vectors:

v · w = |v| |w| cos(θ)

Where θ is the angle between v and w

Special Cases

  • θ = 0°: v · w = |v| |w| (parallel)
  • θ = 90°: v · w = 0 (orthogonal)
  • θ = 180°: v · w = -|v| |w| (opposite)

Finding the Angle

cos(θ) = (v · w) / (|v| |w|)
θ = arccos((v · w) / (|v| |w|))

Python Implementation

import numpy as np

# Real vectors
v = np.array([[3], [4]], dtype=float)
w = np.array([[1], [2]], dtype=float)

# Inner product
inner_prod = np.vdot(v, w)
print(f"v · w = {inner_prod}")
# Output: 11.0

# Complex vectors
psi = np.array([[1/np.sqrt(2)], [1/np.sqrt(2)]], dtype=complex)
phi = np.array([[1], [0]], dtype=complex)

# Inner product (bra-ket)
inner_prod_complex = np.vdot(psi, phi)
print(f"⟨ψ|φ⟩ = {inner_prod_complex}")
# Output: (0.707+0j)

Properties of Inner Product

1. Conjugate Symmetry

⟨v|w⟩ = ⟨w|v⟩*

For real vectors: v · w = w · v

2. Linearity in Second Argument

⟨v|αw + βu⟩ = α⟨v|w⟩ + β⟨v|u⟩

3. Positive Definiteness

⟨v|v⟩ ≥ 0

⟨v|v⟩ = 0 if and only if v = 0

4. Norm Relationship

||v|| = √⟨v|v⟩

Inner product with itself gives squared norm

Quantum Measurement

The inner product is central to quantum measurement!

Measurement Probability

The probability of measuring state |ψ⟩ in basis state |φ⟩:

P(φ) = |⟨φ|ψ⟩|²

Example: Measuring |+⟩ in Computational Basis

|+⟩ = (1/√2)|0⟩ + (1/√2)|1⟩

Probability of measuring |0⟩:

P(0) = |⟨0|+⟩|² = |(1/√2)|² = 1/2 = 50%

Probability of measuring |1⟩:

P(1) = |⟨1|+⟩|² = |(1/√2)|² = 1/2 = 50%
import numpy as np

zero = np.array([[1], [0]], dtype=complex)
one = np.array([[0], [1]], dtype=complex)
plus = (1/np.sqrt(2)) * (zero + one)

# Measurement probabilities
prob_0 = np.abs(np.vdot(zero, plus))**2
prob_1 = np.abs(np.vdot(one, plus))**2

print(f"P(0) = {prob_0:.3f}") # 0.500
print(f"P(1) = {prob_1:.3f}") # 0.500

Orthogonality

Two vectors are orthogonal if their inner product is zero:

⟨v|w⟩ = 0 ⟹ v ⊥ w

Example: Computational Basis States

|0⟩ = [1, 0]ᵀ, |1⟩ = [0, 1]ᵀ

⟨0|1⟩ = (1)(0) + (0)(1) = 0

The basis states are orthogonal!

Orthonormal Basis

A set of vectors is orthonormal if:

  • All vectors are normalized: ⟨vᵢ|vᵢ⟩ = 1
  • All pairs are orthogonal: ⟨vᵢ|vⱼ⟩ = 0 for i ≠ j
⟨vᵢ|vⱼ⟩ = δᵢⱼ

Where δᵢⱼ is the Kronecker delta (1 if i=j, 0 otherwise)

Complex Inner Product Examples

Example 1: Real Components

|ψ⟩ = [0.6, 0.8]ᵀ

|φ⟩ = [0.8, 0.6]ᵀ

⟨ψ|φ⟩ = (0.6)(0.8) + (0.8)(0.6) = 0.96

Example 2: Complex Components

|ψ⟩ = [1/√2, i/√2]ᵀ

|φ⟩ = [1/√2, 1/√2]ᵀ

⟨ψ|φ⟩ = (1/√2)*(1/√2) + (-i/√2)*(1/√2)
= 1/2 - i/2

Example 3: Orthogonal States

|+⟩ = (1/√2)(|0⟩ + |1⟩)

|-⟩ = (1/√2)(|0⟩ - |1⟩)

⟨+|-⟩ = (1/2)(1 - 1) = 0

|+⟩ and |-⟩ are orthogonal!

Example 4: Self Inner Product

|ψ⟩ = [0.6, 0.8]ᵀ

⟨ψ|ψ⟩ = (0.6)² + (0.8)² = 1

For normalized states: ⟨ψ|ψ⟩ = 1

Cauchy-Schwarz Inequality

A fundamental inequality for inner products:

|⟨v|w⟩| ≤ ||v|| ||w||

Equality holds when v and w are parallel

Example

v = [3, 4]ᵀ, w = [1, 2]ᵀ

⟨v|w⟩ = 11

||v|| = 5, ||w|| = √5 ≈ 2.236

|11| ≤ (5)(2.236) = 11.18 ✓

Applications

1. Quantum State Overlap

|⟨ψ|φ⟩|² measures how similar two quantum states are

  • |⟨ψ|φ⟩|² = 1: identical states
  • |⟨ψ|φ⟩|² = 0: orthogonal states
  • 0 < |⟨ψ|φ⟩|² < 1: partially overlapping

2. Expectation Values

Expected value of observable A in state |ψ⟩:

⟨A⟩ = ⟨ψ|A|ψ⟩

3. Projection

Project |ψ⟩ onto |φ⟩:

proj_φ(ψ) = ⟨φ|ψ⟩|φ⟩

4. Gram-Schmidt Orthogonalization

Create orthonormal basis from arbitrary vectors using inner products
