Practice Exercises

Test your understanding of vectors in quantum computing with these exercises. Each exercise includes a detailed solution with step-by-step explanations.

Exercise 1: Vector Normalization

Given the quantum state |ψ⟩ = 3|0⟩ + 4|1⟩, normalize this state so that it represents a valid quantum state.

Solution:

Step 1: Calculate the norm

||ψ|| = √(|3|² + |4|²) = √(9 + 16) = √25 = 5

Step 2: Normalize by dividing by the norm

|ψ_normalized⟩ = (1/5)(3|0⟩ + 4|1⟩) = (3/5)|0⟩ + (4/5)|1⟩

Step 3: Verify normalization

||ψ_normalized|| = √((3/5)² + (4/5)²) = √(9/25 + 16/25) = √(25/25) = 1 ✓

Interpretation:

The normalized state has probability amplitudes 3/5 and 4/5, giving measurement probabilities P(0) = 9/25 = 0.36 and P(1) = 16/25 = 0.64.

Exercise 2: Inner Product and Orthogonality

Consider the states |ψ⟩ = (1/√2)(|0⟩ + |1⟩) and |φ⟩ = (1/√2)(|0⟩ − |1⟩).

(a) Calculate the inner product ⟨φ|ψ⟩
(b) Are these states orthogonal?
(c) What is the probability of measuring |φ⟩ when the system is in state |ψ⟩?

Solution:

(a) Calculate inner product

⟨φ|ψ⟩ = (1/√2)(⟨0| − ⟨1|) · (1/√2)(|0⟩ + |1⟩)
= (1/2)[(⟨0|0⟩ + ⟨0|1⟩) − (⟨1|0⟩ + ⟨1|1⟩)]
= (1/2)[1 + 0 − 0 − 1]
= 0

(b) Orthogonality

Yes, the states are orthogonal because ⟨φ|ψ⟩ = 0. These are the |+⟩ and |−⟩ states, which form an orthonormal basis.

(c) Measurement probability

P(φ) = |⟨φ|ψ⟩|² = |0|² = 0

The probability is zero because the states are orthogonal. If the system is in state |ψ⟩ = |+⟩, it cannot be measured as |φ⟩ = |−⟩.

Exercise 3: Quantum Gates and Transformations

Apply the Hadamard gate H = (1/√2)[[1, 1], [1, -1]] to the state |1⟩.

(a) Calculate the resulting state
(b) What are the measurement probabilities?
(c) Describe the transformation on the Bloch sphere

Solution:

(a) Apply Hadamard gate

H|1⟩ = (1/√2)[1 1] [0]
           [1 -1] [1]

= (1/√2)[1·0 + 1·1]
         [1·0 + (-1)·1]

= (1/√2)[1]
         [-1]

= (1/√2)(|0⟩ − |1⟩) = |−⟩

(b) Measurement probabilities

P(0) = |(1/√2)|² = 1/2 = 0.5
P(1) = |(-1/√2)|² = 1/2 = 0.5

Equal probability of measuring 0 or 1.

(c) Bloch sphere transformation

On the Bloch sphere, the Hadamard gate rotates |1⟩ (south pole) to |−⟩ (negative x-axis). This is a 180° rotation around the axis (x+z)/√2.

Exercise 4: Multi-Qubit Systems and Tensor Products

Calculate the tensor product of |+⟩ ⊗ |0⟩ where |+⟩ = (1/√2)(|0⟩ + |1⟩).

(a) Express the result in the computational basis {|00⟩, |01⟩, |10⟩, |11⟩}
(b) Is this state entangled?
(c) What happens if we apply CNOT to this state?

Solution:

(a) Tensor product calculation

|+⟩ ⊗ |0⟩ = (1/√2)(|0⟩ + |1⟩) ⊗ |0⟩
= (1/√2)(|0⟩ ⊗ |0⟩ + |1⟩ ⊗ |0⟩)
= (1/√2)(|00⟩ + |10⟩)

In vector form:

|ψ⟩ = (1/√2)[1, 0, 1, 0]ᵀ

(b) Entanglement check

No, this state is NOT entangled. It can be written as a tensor product of single-qubit states: |+⟩ ⊗ |0⟩. This is a separable state.

(c) Apply CNOT gate

CNOT(|+⟩ ⊗ |0⟩) = CNOT[(1/√2)(|00⟩ + |10⟩)]
= (1/√2)(CNOT|00⟩ + CNOT|10⟩)
= (1/√2)(|00⟩ + |11⟩)
= |Φ⁺⟩ (Bell state!)

The CNOT gate creates entanglement! The resulting state cannot be written as a tensor product of single-qubit states.

Exercise 5: Density Matrices and Mixed States

Consider a quantum system that is in state |0⟩ with probability 0.7 and state |1⟩ with probability 0.3.

(a) Write the density matrix for this mixed state
(b) Calculate Tr(ρ) and Tr(ρ²)
(c) Is this a pure state or mixed state?
(d) What are the measurement probabilities in the computational basis?

Solution:

(a) Density matrix

ρ = 0.7|0⟩⟨0| + 0.3|1⟩⟨1|

= 0.7[1 0] + 0.3[0 0]
      [0 0]       [0 1]

= [0.7 0 ]
  [0 0.3]

(b) Calculate traces

Tr(ρ) = 0.7 + 0.3 = 1.0 ✓ (normalized)

ρ² = [0.7 0 ][0.7 0 ] = [0.49 0 ]
     [0 0.3][0 0.3]   [0 0.09]

Tr(ρ²) = 0.49 + 0.09 = 0.58

(c) Pure or mixed?

This is a MIXED state because Tr(ρ²) = 0.58 < 1. For a pure state, we would have Tr(ρ²) = 1. The purity of 0.58 indicates partial mixing.

(d) Measurement probabilities

P(0) = Tr(|0⟩⟨0| ρ) = Tr([1 0][0.7 0 ]) = 0.7
                           [0 0][0 0.3]

P(1) = Tr(|1⟩⟨1| ρ) = 0.3

The measurement probabilities are simply the diagonal elements of the density matrix: 70% chance of measuring |0⟩ and 30% chance of measuring |1⟩.

Bonus Exercise: Bloch Sphere Representation

A qubit state is represented on the Bloch sphere with spherical coordinates θ = π/3 and φ = π/4.

(a) Write the state in ket notation
(b) Calculate the Bloch vector (x, y, z)
(c) What are the measurement probabilities?
(d) Which gate would rotate this state to |0⟩?

Solution:

(a) State in ket notation

|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ) sin(θ/2)|1⟩
= cos(π/6)|0⟩ + e^(iπ/4) sin(π/6)|1⟩
= (√3/2)|0⟩ + e^(iπ/4)(1/2)|1⟩
≈ 0.866|0⟩ + (0.354 + 0.354i)|1⟩

(b) Bloch vector

x = sin(θ) cos(φ) = sin(π/3) cos(π/4) ≈ 0.612
y = sin(θ) sin(φ) = sin(π/3) sin(π/4) ≈ 0.612
z = cos(θ) = cos(π/3) = 0.5

Bloch vector: (0.612, 0.612, 0.5)

(c) Measurement probabilities

P(0) = cos²(θ/2) = cos²(π/6) = (√3/2)² = 3/4 = 0.75
P(1) = sin²(θ/2) = sin²(π/6) = (1/2)² = 1/4 = 0.25

Or using z-coordinate:
P(0) = (1 + z)/2 = (1 + 0.5)/2 = 0.75 ✓
P(1) = (1 - z)/2 = (1 - 0.5)/2 = 0.25 ✓

(d) Gate to rotate to |0⟩

To rotate this state to |0⟩ (north pole), we need a rotation that:

  • First rotates by -φ around the z-axis: Rz(-π/4)
  • Then rotates by -θ around the y-axis: Ry(-π/3)
Combined gate: Ry(-π/3) Rz(-π/4)
